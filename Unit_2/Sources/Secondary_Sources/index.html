Citing these readings

Cite the book pages.

Use the full footnote citation the first time you cite a book and the shortened form afterward, even when you cite another selection from the same book. Use the original book pages, not reader page numbers.

If a historian quotes a primary source you have not read yourself, use a “quoted in” note. Include only works you actually use.
